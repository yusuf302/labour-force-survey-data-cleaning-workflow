📌 Overview

This document presents the data cleaning and preparation workflow used in an empirical analysis of labour force participation. The pipeline demonstrates how large-scale survey data can be processed efficiently using R.

The goal is to ensure reproducibility, transparency, and clarity in data handling.

⚙️ Setup

#| message: false #| warning: false  # Load libraries library(tidyverse) library(haven) library(labelled)

📥 Data Import

# Import dataset (example path) # Replace with your actual file path  data_raw <- read_sav("ILFS2024-URT-FINAL.sav")  # Preview structure glimpse(data_raw)

🔎 Variable Inspection

# Check labels for key variables  var_label(data_raw$ILO_LFS) val_labels(data_raw$ILO_LFS)  var_label(data_raw$Q04_MEM_SEX) val_labels(data_raw$Q04_MEM_SEX)

🎯 Create Labour Force Participation Variable

data <- data_raw %>%   mutate(     lfp_binary = ifelse(ILO_LFS %in% c(1,2), 1, 0)   )  table(data$lfp_binary)

👥 Filter Youth Sample

data_youth <- data %>%   filter(Q06B_MEM_AGE >= 18 & Q06B_MEM_AGE <= 35)  summary(data_youth$Q06B_MEM_AGE)

🚻 Gender Variable

data_youth <- data_youth %>%   mutate(     male = ifelse(Q04_MEM_SEX == 1, 1, 0)   )  table(data_youth$male)

🎓 Education Categorization

data_youth <- data_youth %>%   mutate(     educ_cat = case_when(       Q11D <= 7 ~ 1,       Q11D %in% 11:17 ~ 2,       Q11D >= 18 ~ 3,       TRUE ~ 0     )   )  table(data_youth$educ_cat)

💍 Marital Status Variables

data_youth <- data_youth %>%   mutate(     cohabiting_d = ifelse(Q09_MARSTAT == 3, 1, 0),     prev_married_d = ifelse(Q09_MARSTAT %in% c(4,5,6), 1, 0)   )  table(data_youth$cohabiting_d) table(data_youth$prev_married_d)

🏠 Household Size Construction

data_youth <- data_youth %>%   group_by(EA, HHNUMBER) %>%   mutate(hhsize = n_distinct(Q01_PERSONNO)) %>%   ungroup()  summary(data_youth$hhsize)

🎓 Training Variable

data_youth <- data_youth %>%   mutate(     trained = ifelse(Q11G == 1, 0, 1)   )  table(data_youth$trained)

📊 Final Dataset

final_data <- data_youth %>%   select(     lfp_binary,     male,     Q06B_MEM_AGE,     educ_cat,     hhsize,     trained,     cohabiting_d,     prev_married_d   ) %>%   na.omit()  summary(final_data)

📌 Conclusion

This pipeline demonstrates a structured approach to transforming raw survey data into an analysis-ready dataset. The workflow ensures consistency, reproducibility, and clarity in empirical research.

The processed dataset can now be used for econometric modeling using tools such as Stata or R.
